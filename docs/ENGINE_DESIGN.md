# 게임 엔진 설계 (v0.1)

> FM25의 핵심 재미(영입·팀 구성·시즌 성적·육성)를 남기고 무거운 부분은 덜어낸 간편화 버전.
> 차별점: 2000/01부터 시작, 실제 시즌별 능력치 반영, **숨은 속성 육성**, **호칭 시스템**, 한국어 기반.

## 1. 기술 스택

- React + TypeScript (Vite), Tailwind CSS, Zustand, IndexedDB, Vitest
- **엔진은 화면과 분리된 순수 TypeScript 모듈**

## 2. 전체 구조

```
[원본 데이터]  data/seasons/...  (읽기 전용, 출처 기반)
      ↓ 빌드 (M1)
[게임 DB]     시즌별 게임용 파일
      ↓ 새 게임 시작 시 복사
[월드 상태]    세이브 = 게임 세계 전체 (엔진이 수정)
      ↓↑
[화면(UI)]
```

원칙
1. 엔진은 화면을 모른다. 화면 없이 시즌 전체를 돌릴 수 있어야 한다 (`npm run sim`).
2. 결정론적: 모든 랜덤은 세이브의 시드로만 → 재현·테스트 가능.
3. `advanceDay(world) → { world, events[] }` — 이벤트가 받은편지함·뉴스가 된다.

## 3. 하루 진행 루프

```
1. 달력 (이적시장 열림/닫힘, 계약 만료, 시즌 전환)
2. 오늘 경기 → 결과·순위·체력·폼·부상·행동 기록
3. 훈련·회복·육성 프로그램 진행
4. AI 구단 행동 (이적·계약, 하루 몇 건)
5. 재정 (주급 주 단위, 수입 경기일)
6. 월 1회: 호칭 판정
7. 이벤트 → 받은편지함
```

- 5개 리그 모두 매일 실제로 진행한다 (이적 시장이 살아 있도록).
- 사용자 경기만 상세 모드, 나머지는 빠른 모드.

## 4. 모듈

| 모듈 | 역할 | 단계 |
|---|---|---|
| calendar | 날짜, 시즌 일정, 이적시장 | 1차 |
| fixtures | 리그 일정 (라운드 로빈, 홈·원정) | 1차 |
| match | 경기 계산 (구간 진행) | 1차 |
| standings | 순위 (승점 → 골득실 → 다득점) | 1차 |
| squad | 선발·후보·벤치, 포메이션, AI 자동 선택 | 1차 |
| condition | 체력·폼·부상 | 1차 |
| development | 시즌 전환 능력치, 성장/노화, 육성 프로그램 | 1차/2차 |
| hidden | 숨은 속성 | 1차/2차 |
| traits | 호칭 (행동 기록·판정·효과) | 1차/2차 |
| transfer | 이적·임대·계약·FA | 2차 |
| finance | 수입·지출, 성적 연동 | 2차 |
| board | 구단 목표, 해임 | 2차 |

## 5. 경기 엔진

- 90분을 **구간(예: 5분)** 으로 나눠 진행. 구간마다 양 팀 공격·중원·수비 전력, 홈 이점, 체력, 전술로 득점 확률 계산.
- **경기 중 전술 지시**: 멈추고 공격·수비 성향, 압박 강도, 포메이션, 교체 변경 → 남은 구간부터 반영.
- 1단계: 점수·득점자·카드 정도. 2단계: 분 단위 문자 중계 (같은 구간 구조 재사용).
- 검증: 경기당 평균 2.6~2.8골, 홈 승률 약 45%, 전력 순위와 최종 순위의 상관.

## 6. 능력치 계산

```
경기에 쓰는 능력치 = 그 시즌 실제 능력치 (기준선)
                  + 육성 보정치   (세이브에 저장, 시즌이 바뀌어도 유지, 천천히 감소)
                  + 호칭 효과
                  + 컨디션 (체력·폼·사기)
```

- **능력치는 실제를 따르고, 소속은 게임 세계를 따른다.**
- 미래 선수는 실제 데뷔 시즌에 실제 소속 구단으로 등장한다. 그 구단 선수단이 꽉 찼으면 FA로 등장한다.
- 실제 데이터가 끝난 뒤(2026/27~)에는 성장 엔진(나이 곡선·잠재력·출전·랜덤)이 이어받는다.
- 잠재력 상한과 투자 효율 감소로 "돈으로 슈퍼 선수 만들기"를 막는다.

## 6-1. 컨디션 · 경기 기복

| 요소 | 내용 | 변화 |
|---|---|---|
| 체력 | 경기·훈련 소모, 휴식 회복. 낮으면 후반 능력치↓·부상↑ | 매일, 경기 중 구간마다 |
| 컨디션 | 휴식, 훈련 강도, 일정 밀도, 원정, 나이, 프로의식, 부상 복귀 직후 | 매일 조금씩 |
| 경기 당일 컨디션 | 킥오프 때 컨디션 기준으로 한 번 더 뽑음 → 인생 경기/최악의 경기 | 경기마다 |
| 폼 | 최근 5경기 평점 흐름 | 경기마다 |
| 사기 | 출전 시간, 결과, 계약·역할 만족, 팀 분위기 | 주 단위 |
| 경기 감각 | 결장 시 하락, 출전 시 회복 | 경기마다 |

- 보정 예시: 당일 컨디션 ±8%, 폼 ±5%, 사기 ±5%, 체력 60% 이하부터 하락.
- 기복 폭은 숨은 속성 **꾸준함**, 큰 경기 보정은 **큰 경기 강도**·호칭으로 결정.
- 표시: 컨디션 5단계 아이콘 + 체력 %. 감독 도구: 로테이션, 휴식, 훈련 강도, 피지컬 코치·의료진.
- AI 구단도 같은 규칙 → 강팀도 주중 경기 뒤 이변.

## 7. 숨은 속성

꾸준함, 큰 경기 강도, 프로의식, 부상 경향, 적응력, 야망, 기질, 충성도

- 출처가 없으므로 **게임이 생성한 값**(시드 기반)으로 세이브 안에만 저장한다. 출처 데이터와 섞지 않는다.
- 화면에는 직접 수치 대신 코치 평가(예: "매우 꾸준함")로 보여준다.

### 육성 프로그램

```
성공 확률 = 기본값 + 투자 금액(효율 점점 감소) + 코치 수준·전문 분야
          + 소속 기간 + 나이(어릴수록↑) + 멘토
```

- 성공 → **일시적 변화**(몇 달) → 유지하거나 소속이 길어지면 확률적으로 **영구 변화**.
- 실패 → 돈·시간 소모, 사기 소폭 하락 가능.

### 스탯 육성 방법

| 방법 | 효과 |
|---|---|
| 집중 훈련 | 특정 능력치 성장↑, 다른 능력치 성장↓ |
| 포지션 전환 | 시간 필요, 적성에 따라 성공 여부 |
| 멘토링 | 베테랑의 숨은 속성이 어린 선수에게 조금씩 옮겨감 |
| 출전 시간 | 경기를 뛰어야 많이 성장 (임대의 의미) |
| 시설·코치 | 전체 성장률 |

## 8. 호칭 시스템

- 경기 행동 누적 + 시간에 따라 **낮은 확률로** 붙고, 플레이 방식이 바뀌면 바뀌거나 사라진다.
- 선수당 최대 3개. **사용자 구단·AI 구단 모두 동일 적용.**
- 에이스(핵심·출전 많음) 보정으로 주전급이 호칭을 달기 쉽다.
- 기본은 **모든 선수가 호칭 없이 시작**. 유명 선수 호칭 "전설 프리셋"은 2차 옵션(설정에서 켜고 끔).
- **실존 인물 보호 규칙**: 전설 프리셋에는 **완전 긍정 호칭만** 넣는다 (양날의 검 · 완전 부정 호칭을 실제 선수에게 미리 붙이지 않음). 게임 진행 중 생긴 호칭 · 코치 평가는 화면에 "이 세이브에서 게임이 만든 평가"로 표시해 실제 선수에 대한 평가로 오해되지 않게 한다.

### 판정

```
매달 1회:
확률 = 기본 1~3% (완전 긍정 호칭은 더 낮음)
     + 기준 대비 행동 누적량 + 에이스 보정 + 소속 기간
```

### 종류

**양날의 검**

| 호칭 | 조건 | + | − |
|---|---|---|---|
| 악동 | 몸싸움·파울 + 공격 포인트 | 몸싸움, 슈팅 +1 | 반칙 확률↑, 침착성 −2 |
| 두 개의 폐 | 활동량 상위 + 출전 많음 | 활동량, 시야 +1 | 부상 확률↑ |
| 해결사 | 후반 결승·동점골 반복 | 결정적 순간 침착성 +2 | 평소 꾸준함 −1 |
| 큰 경기의 사나이 | 강팀전·더비 활약 | 큰 경기 보정 +2 | 약팀전 집중력 −1 |
| 철벽 | 무실점 누적 (DF·GK) | 수비 위치선정 +2 | 빌드업 패스 −1 |
| 마에스트로 | 키패스·어시스트 누적 | 패스, 시야 +2 | 몸싸움 −1 |
| 스피드스타 | 드리블 돌파 누적 | 가속 +2 | 노화 가속 |
| 캡틴 | 주장 장기 수행 | 팀 사기 보정 | 벤치 시 불만 큼 |

**완전 긍정 (조건 까다로움, 확률 낮음)**

| 호칭 | 조건 | 효과 |
|---|---|---|
| 구단 레전드 | 한 구단 장기 소속(예: 8시즌+) + 핵심 활약 + 우승 | 팀 사기·팬 여론↑, 충성도 최대, 노화 완화 |
| 팀플레이어 | 어시스트·패스 성공·연계 누적, 불화 없음 | 주변 선수 호흡 보정↑ |
| 허슬 플레이 | 태클·압박·활동량 꾸준히 상위 | 활동량·적극성 +1, 팀 압박 보정 |
| 프로페셔널 | 장기간 부상·징계 없음, 꾸준한 평점 | 성장 속도↑, 노화 완화 |
| 멘토 | 베테랑 + 어린 선수 성장 기여 | 같은 포지션 유망주 성장↑ |
| 원클럽맨 | 데뷔 구단에서만 장기 활약 | 충성도 최대, 재계약 쉬움, 사기↑ |

**완전 부정**

| 호칭 | 조건 | 효과 |
|---|---|---|
| 트러블메이커 | 경고·퇴장·불화 반복 | 경고 확률↑, 팀 사기↓ |
| 유리몸 | 부상 반복 | 부상 확률↑ |
| 새가슴 | 큰 경기 부진 반복 | 큰 경기 능력치 −2 |
| 먹튀 | 고액 이적 후 장기 부진 | 사기↓, 팬 여론↓ |

### 변화·소멸
- 나쁜 호칭은 육성 프로그램으로 제거를 시도할 수 있다 (트러블메이커 → 멘탈 코칭·멘토, 유리몸 → 의료진·재활 투자).
- 좋은 호칭도 그 행동이 오래 끊기면 사라질 수 있다. 단, 구단 레전드·원클럽맨은 영구.

## 9. 월드 상태 (세이브)

```ts
World {
  meta: { version, seed, date, userClubId, mode }
  players: Record<id, PlayerState>   // 능력치 보정, 숨은 속성, 호칭, 행동 기록, 체력·폼·부상, 계약
  clubs: Record<id, ClubState>       // 선수단, 포메이션, 전술, 재정, 코치·시설
  competitions: Record<id, { season, fixtures[], table[] }>
  inbox: Event[]
  history: { seasons: [...] }
}
```

- ID로 연결. 세이브 버전 번호 + 변환(migration) 지원.

## 10. 폴더 구조

```
game/
  src/engine/      순수 TS 모듈
  src/data/        게임 DB 로딩, 타입
  src/store/       Zustand
  src/ui/          React 화면

```

## 11. 단계

- **1차**: calendar, fixtures, match(구간·전술 지시·점수), standings, squad, condition, 기본 성장, 숨은 속성 표시, 호칭 1차(행동 기록, 호칭 15~20개, 획득·소멸)
- **2차**: 육성 프로그램·멘토링, 나쁜 호칭 제거, 이적·재정·보드, 문자 중계, 전설 프리셋
- **이후**: 컵·유럽 대회, 2부 리그, 유스, 코치진 고용
